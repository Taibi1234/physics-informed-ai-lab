05 / READ BEFORE GENERALIZING

What these results do—and do not—show.

Small synthetic scope +

These are controlled educational experiments on harmonic oscillators, not benchmarks across complex physical systems. Five seeds support descriptive summaries, not claims of statistical significance.

Different metrics answer different questions +

Position RMSE measures trajectory accuracy against the reference. Physics-residual RMSE measures equation satisfaction. A model can improve one without improving the other.

Optimization remains part of the result +

The fixed architecture and Adam configuration do not represent every possible training strategy. Outliers and population standard deviations are preserved to make run-to-run variability visible.

Reproduction is public +

Raw metrics, dense predictions, configurations, mathematical verification, and training scripts are preserved in the repository. The website is a view of those artifacts, not an independent result source.
